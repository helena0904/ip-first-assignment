My First Program

The first thing I wrote in Python was print("Hello, World!"). Later I wrote this loop:

In C++, the same idea looks like this:

using namespace std;

    for (int i = 0; i < 3; i++) {
        cout << "Hello " << i << endl;
    }
    return 0;
}
